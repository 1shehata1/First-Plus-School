# فيرست بلس — نسخة ملفات منفصلة

## التشغيل
فك ضغط المجلد بالكامل وافتح `index.html`، أو افتح `site/index.html` مباشرة.
لوحة المدير: `admin/admin.html`.
لا تنقل ملف HTML وحده؛ يحتاج ملفات CSS وJavaScript ومجلد assets المجاورين.

يمكن تشغيل خادم محلي من داخل المجلد:
```bash
python -m http.server 8000
```
ثم فتح http://localhost:8000 في متصفحك. لا تحتاج إلى npm أو خطوات بناء.

## تنظيم المشروع
```
index.html              مدخل إلى الموقع
site/
  index.html            هيكل الموقع والصفحات العامة
  styles.css            التصميم والمقاسات والحركات
  script.js             التنقل والنماذج والصور والعارض
admin/
  admin.html            هيكل لوحة المدير
  styles.css            تصميم لوحة المدير
  script.js             التفاعلات والبيانات التجريبية
assets/
  images/               الصور والشعار والصور المصغرة
  fonts/                الخطوط المحلية
```

الصفحات الفرعية العامة تُعرض ديناميكيًا بواسطة site/script.js، وليست ملفات HTML مستقلة لكل صفحة.
تم نقل كتل CSS وJavaScript إلى ملفات منفصلة، وتبقى بعض الخصائص والأحداث المضمّنة ضمن HTML والقوالب الديناميكية للحفاظ على سلوك النسخة الحالية.
كل الصور والخطوط محلية؛ لا يحتاج التصميم إلى موارد خارجية.

## حدود النسخة
- نموذج واجهات تفاعلي، وليس نظامًا إنتاجيًا مكتملًا.
- لا توجد مصادقة أو قاعدة بيانات أو صلاحيات فعلية.
- تعديلات لوحة المدير في الذاكرة فقط وتُمسح عند إعادة التحميل.
- نماذج الموقع لا ترسل البيانات ولا تحفظها.
- الدفع والإعلانات لا ينفّذان تحصيلًا أو إرسالًا فعليًا.
- الإنجليزية ترجمة جزئية للرئيسية.
- لا تدخل بيانات شخصية حقيقية؛ يُراجع المحتوى والتواريخ والموافقات قبل النشر.
